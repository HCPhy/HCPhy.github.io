Longest Increasing Subsequence (LIS)

从 Pareto Frontier 到 Patience Sorting：为什么 Greedy 和 Dominance Pruning 能把 LIS 的状态空间压缩到只需一次 Binary Search？

October 17, 2026  ·  Algorithm Notes  ·  C++

GreedyDominance PruningBinary Search
The idea in one line

核心思想：Greedy + Dominance Pruning + Binary Search

1. State Representation

维护所有非劣状态（Pareto Frontier）：

\[ S = \{(a,\ell_a)\} \]
  • a：递增子序列的结尾值（tail）。
  • ℓ_a：该子序列的长度。

对于新元素 b，希望接到结尾小于 b 的最长 subsequence 后面：

\[ \boxed{\ell_b = 1 + \max_{a\lt b}\ell_a} \]

如果没有合法前驱，最大值视为 0，单个元素构成长度为 1 的 subsequence。

2. Greedy — Dominance Pruning

如果两个状态满足：

\[ \boxed{a\le b,\quad \ell_a\ge\ell_b} \]

那么 (a, ℓ_a) dominates (b, ℓ_b)。因为前者：

  • 长度不短于后者。
  • 结尾不大于后者，更容易被未来元素扩展。

因此可以安全删除 (b, ℓ_b)。

维护 Pareto Frontier 后：

\[ a_1\lt a_2\lt\cdots\lt a_L,\qquad \ell_1\lt\ell_2\lt\cdots\lt\ell_L \]

且这些长度恰好为 \(1,2,\ldots,L\)。所以 prev(lower_bound(b)) 就是最优前驱；如果没有比 b 更小的 tail，就从长度 1 开始。

3. 从 TreeMap 到 Patience Sorting

定义：

\[ \boxed{\mathrm{tails}[k]=\text{长度为 }k+1\text{ 的递增子序列的最小结尾}} \]

对于每个新元素 x：

  1. lower_bound(x)：找到第一个 tail >= x。
  2. 如果存在，用 x 替换它（更新这一长度的最优结尾）。
  3. 否则，新增一个 tail（LIS 长度增加）。

由于 tails 严格递增，可以直接 Binary Search。

C++ · lower_bound 
class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;

        for (int x : nums) {
            auto it = lower_bound(tails.begin(), tails.end(), x);
            if (it == tails.end()) tails.push_back(x);
            else *it = x;
        }

        return tails.size();
    }
};
Time complexity\(O(n\log n)\)
Space complexity\(O(n)\)

注意：tails 整个数组不一定对应某一条实际存在的 subsequence；但每个 tails[k] 都是某条长度为 k+1 的递增子序列的真实结尾。

4. Greedy vs DP

传统 DAG DP：

\[ dp[i] = 1 + \max_{\substack{j\lt i \\ \mathrm{nums}[j]\lt\mathrm{nums}[i]}} dp[j] \]

复杂度为 \(O(n^2)\)；无合法前驱时，最大值同样视为 0。

Patience Sorting 则通过 dominance pruning，避免枚举所有合法前驱。

方法核心优化
DFS + Memo避免重复计算相同状态
Greedy + Dominance直接删除永远不可能更优的状态

5. Generalizable Insight

与 Monotonic Deque 类似，LIS 也是维护一个 Pareto Frontier：

\[ \boxed{ \text{Candidates}\rightarrow\text{Dominance Pruning} \rightarrow\text{Monotonic Frontier}\rightarrow\text{Binary Search} } \]

Key takeaway：遇到优化问题时，不仅考虑如何 memoize，还要考虑：

Can one state dominate another for all possible future decisions?

如果能证明 dominance relation，就可能通过 Greedy Pruning 大幅压缩状态空间。
